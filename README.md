## About

Lecco, class of 1997. Since 2016 I’ve been doing ICT and web systems: taking on messy projects, keeping a practical bias, and caring more about what still works next year than about the stack of the week.

I like leading complex work. I like automation that removes labor instead of adding ceremony. Lately I spend time teaching agents to behave like a lazy senior: one sharp change, enough context, the answer on the first line.

Off-screen: sports, sailing, food and wine.

## What I usually do

Web systems, integrations, automations. Sometimes a product from scratch. More often the glue that makes existing pieces behave as one thing — APIs, workflows, agents, the unglamorous path from “it works on my machine” to “it runs without me”.

I also run two holiday homes with a partner, and I treat them like products: Lake Como and Fuerteventura, with automated check-in, guest messaging, channel sync, and dynamic pricing.

- [Mandello Horizon](https://mandellohorizon.it) — Mandello del Lario, Lake Como
- [Cotillo Horizon](https://cotillohorizon.es) — El Cotillo, Fuerteventura

## Stars I keep close

I don’t star much. The ones that stay are there because they change how I work — or how I want to work.

### How an agent should think

- **[ponytail](https://github.com/DietrichGebert/ponytail)** — the best code is the code you never wrote. A lazy-senior agent beats a file factory.
- **[i-have-adhd](https://github.com/ayghri/i-have-adhd)** — put the answer first. No three-paragraph wind-up.
- **[impeccable](https://github.com/pbakaus/impeccable)** — design is not an afterthought. If the agent has no visual language, it improvises.

### How it holds context

- **[graphify](https://github.com/Graphify-Labs/graphify)** — a codebase (docs, schemas, configs) becomes a graph you can query. No “read everything and hope”.
- **[Graft](https://github.com/trailhq/Graft)** — same instinct: make the agent understand *this* project, not a generic one.
- **[compound-engineering-plugin](https://github.com/EveryInc/compound-engineering-plugin)** — idea to review as a real loop, not a new process every chat.

### Skills, not prompts

- **[mattpocock/skills](https://github.com/mattpocock/skills)** — skills from a real `.agents` directory.
- **[addyosmani/agent-skills](https://github.com/addyosmani/agent-skills)** — the same craft, with a production bar.
- **[thebous-os](https://github.com/TheBous/thebous-os)** — a personal OS for the workday: briefing, review, PRs, shutdown. I use it.

### The rest I actually need

- **[rtk](https://github.com/rtk-ai/rtk)** — fewer tokens wasted on everyday commands. One binary, no theatre.
- **[Scrapling](https://github.com/D4Vinci/Scrapling)** — when the data is not behind a decent API, you need something that survives the next markup change.
